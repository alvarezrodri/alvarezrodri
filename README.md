## 🚀 Projetos em destaque

### 🏥 [MedData — Inteligência para Gestão Hospitalar](https://github.com/alvarezrodri/projeto-meddata)

<img src="https://github.com/user-attachments/assets/e8e18a8a-e85a-48f6-a564-b0327ad5fab6" alt="Banner do projeto MedData" width="100%" />

Solução desenvolvida para o **Challenge Oracle 2026**, com dados públicos de internações, leitos e municípios de São Paulo. Integra um pipeline com camadas **Bronze, Silver e Gold**, carga analítica no **Oracle Autonomous Database**, dashboard interativo e **três agentes de IA** para apoiar análises de capacidade, previsão e otimização hospitalar.

**Tecnologias:** Python · Oracle Autonomous Database · SQL · Streamlit · Plotly · LangChain · RAG

**Destaque:** integração de dados de SIH/DataSUS, CNES e IBGE e exploração de informações em linguagem natural.

[📂 Ver repositório e arquitetura](https://github.com/alvarezrodri/projeto-meddata) · [📊 Acessar dashboard Oracle APEX](https://g64eedc89970a8a-meddataadb.adb.sa-saopaulo-1.oraclecloudapps.com/ords/r/meddata/meddata-dashboard/home)
